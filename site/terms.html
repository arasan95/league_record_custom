利用規約

最終更新日: 2026-07-18

本規約は、LeagueRecordの任意のYouTubeアップロード機能の利用条件を定めるものです。

1. 利用者の責任

利用者は、アップロードする動画について必要な権利および権限を有することを確認したうえで本機能を利用します。利用者は、YouTubeの利用規約、コミュニティガイドラインその他の適用される規約および法令を遵守するものとします。

2. 投稿操作

本アプリは、利用者が明示的に投稿を開始した場合にのみ、利用者が選択したYouTubeアカウントおよびチャンネルへ動画を送信します。投稿内容、公開範囲、子ども向け設定は利用者の責任で確認してください。

3. サービスの制限

YouTube、Google、ネットワーク環境、アカウント状態、API利用上限その他の事情により、本機能が利用できない、投稿が失敗する、または投稿動画がYouTube側で制限・削除される場合があります。

4. 接続解除

利用者は本アプリ内の操作によりGoogle接続を解除できます。接続解除後、YouTube上にすでに投稿された動画は自動では削除されません。必要に応じて利用者自身がYouTube Studioから管理してください。

5. 変更

本機能または本規約を変更・停止する場合があります。変更後の規約は、このページで公開した時点から適用されます。

6. 問い合わせ

GitHub Issuesからお問い合わせください。認証情報や個人情報は送信しないでください。
