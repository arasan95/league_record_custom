LeagueRecord

LeagueRecord公式ホームページ

LeagueRecord は、League of LegendsのゲームプレイをWindows PCへローカル録画し、利用者が自分の録画・クリップを確認して共有できるようにするデスクトップアプリです。

LeagueRecordの目的と主な機能

LeagueRecordの目的は、利用者が自分のゲームプレイを録画して振り返り、必要に応じて共有できるようにすることです。録画ファイルは利用者のPC上の指定フォルダーに保存され、LeagueRecordは録画ファイルを開発者のサーバーへ自動送信しません。

  • League of Legendsのゲームプレイをローカルへ録画します。
  • 利用者が作成した録画およびクリップを一覧で確認できます。
  • 利用者が選択した録画を、任意で外部サービスへ共有できます。

任意のYouTubeアップロード機能

LeagueRecordは、利用者が明示的に選択した完成済みの録画またはクリップを、利用者自身のYouTubeチャンネルへアップロードするために、YouTube Data APIの youtube.upload 権限を使用します。

この機能は任意です。LeagueRecordは、利用者がGoogleアカウントを接続し、投稿する動画、タイトル、説明、公開設定および子ども向け設定を選び、最終確認した場合にのみ動画をYouTubeへ送信します。利用者はアプリ内でGoogle接続をいつでも解除できます。

LeagueRecordは、Googleアカウントのパスワードを取得せず、OAuth認証トークンやアップロードした動画を開発者のサーバーへ保存しません。詳細はプライバシーポリシーを確認してください。

About LeagueRecord

LeagueRecord is a Windows desktop application for locally recording League of Legends gameplay, reviewing recordings and clips, and sharing a user-selected video when the user chooses to do so.

Its optional YouTube feature uses the YouTube Data API only to upload a recording or clip explicitly selected by the user to the user's own YouTube channel. LeagueRecord uploads nothing without the user's Google authorization, upload settings, and final confirmation.
