Windows desktop game recorder

LeagueRecord試合を録画し、振り返りをもっと簡単に。

LeagueRecordは、League of LegendsのゲームプレイをWindows PCへローカル録画し、重要な場面を素早く見返してクリップとして残せるオープンソースのデスクトップアプリです。

Windows版をダウンロード GitHubで見る
  • 録画はPC内に保存
  • 無料・オープンソース
  • Windows x64対応

Designed for review

録画するだけで終わらない。
振り返りに必要な機能をひとつに。

試合の記録から、見たい場面への移動、クリップの書き出しまで。League of Legendsの振り返りをスムーズにします。

01 / RECORD

試合をローカル録画

ゲームモードを判別して試合を記録。手動録画用のホットキーやタスクバーの録画状態表示にも対応しています。

02 / REVIEW

見たい場面へすぐ移動

キル、デス、アシスト、オブジェクトなどのイベントをタイムラインに表示。試合全体を探し回る手間を減らします。

03 / CLIP

A-Bループとクリップ作成

開始点と終了点を指定して繰り返し確認し、そのまま必要な区間だけを動画クリップとして書き出せます。

04 / AUTOMATION

再生操作を自動化

録画選択時の自動再生や、イベント移動時の停止・再生・選択・ポップアップを好みに合わせて設定できます。

05 / DATA

ゲーム情報をローカル表示

ローカルのWADデータを利用し、チャンピオンのスキル説明などを画面上で確認できます。

06 / SCOREBOARD

試合情報をまとめて確認

スコアボードで参加プレイヤーやビルドを確認。プレイヤープロフィールへの移動にも対応しています。

Simple workflow

記録から共有まで、迷わない。

試合後の振り返りを、3つの流れで完結できます。

1

試合を記録

League of Legendsをプレイ。録画は指定したPC内のフォルダーへ保存されます。

2

イベントから振り返る

録画一覧とタイムラインを使い、確認したいプレイへ素早く移動します。

3

クリップとして残す

必要な区間を切り出して保存。任意で自分のYouTubeチャンネルへ共有できます。

Optional YouTube upload

選んだ動画だけを、あなたのチャンネルへ。

LeagueRecordのYouTubeアップロード機能は任意です。利用者が明示的に選択した完成済みの録画またはクリップを、利用者自身のYouTubeチャンネルへアップロードするために、YouTube Data APIのyoutube.upload権限を使用します。

  • Googleアカウントへの接続は利用者が開始します。
  • 動画、タイトル、説明、公開設定、子ども向け設定を確認してから送信します。
  • 利用者の最終確認なしに動画をアップロードしません。
  • アプリ内からGoogleアカウントとの接続を解除できます。
プライバシーポリシー 利用規約

Local first

あなたの録画は、あなたのPCに。

録画ファイルは利用者が指定したPC内のフォルダーへ保存されます。LeagueRecordは録画ファイルを開発者のサーバーへ自動送信しません。

  • Googleアカウントのパスワードを取得しません。
  • OAuth認証トークンやアップロード動画を開発者のサーバーへ保存しません。
  • ソースコードをGitHubで公開しています。

About LeagueRecord

LeagueRecord is an open-source Windows desktop application for locally recording League of Legends gameplay, reviewing matches through an event timeline, creating clips, and optionally uploading a user-selected recording or clip to the user's own YouTube channel. Nothing is uploaded without the user's Google authorization, upload settings, and final confirmation.
