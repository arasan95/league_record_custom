プライバシーポリシー

最終更新日: 2026-07-18

このプライバシーポリシーは、LeagueRecord（以下「本アプリ」）のGoogle認証、任意のYouTubeアップロードおよび試合データ共有機能に適用されます。

1. 本機能の目的

本アプリは、利用者がPCに保存した完成済みの録画またはクリップを、利用者が明示的に選択して利用者自身のYouTubeチャンネルへアップロードできるようにします。本アプリは、利用者の明示的な操作なしに動画をアップロードしません。

2. Google・YouTubeから扱う情報

本機能はGoogle OAuth 2.0を使用し、本人確認のための openid・email、動画投稿のためのYouTube Data API youtube.upload、利用者が本アプリから共有した動画の存在・公開状態を確認するための youtube.readonly 権限を要求します。読み取り権限は、YouTube側で削除済みの動画に対応する共有試合データをFirestoreから整理する目的に限って使用します。氏名やプロフィール画像を取得する profile 権限は要求しません。

  • メールアドレスはFirebase Authenticationで利用者を識別し、共有データの所有者を管理するために使用します。試合JSONには含めず、公開しません。
  • Googleのaccess tokenおよびrefresh tokenは利用者のPC上でOSの暗号化機能を用いて保存します。
  • ID tokenはFirebaseのログイン確立に短時間だけ使用し、試合JSONや開発者のデータベースへ保存しません。
  • 認証トークン、Googleアカウントのパスワード、YouTubeのログイン情報を開発者のサーバーへ送信・保存しません。
  • 本アプリは、動画アップロード以外の目的でYouTubeデータを販売、共有、広告利用しません。

3. YouTubeへ送信する情報

利用者が投稿を開始した場合に限り、本アプリは次の情報をYouTubeへ送信します。

  • 利用者が選択した動画ファイル
  • 利用者が入力したタイトルおよび説明
  • 公開範囲、子ども向け設定、カテゴリなどの投稿設定

投稿内容および公開範囲は利用者が確認して決定します。YouTubeに投稿された動画およびそのデータには、YouTubeの利用規約とプライバシーポリシーが適用されます。

4. Firestoreへ保存する試合データ

利用者が試合データの共有を選択した場合、本アプリはYouTube動画IDと、タイムラインやスコアボードの表示に必要な試合JSONをGoogle Cloud Firestoreへ保存します。Googleのメールアドレス、認証トークン、PC上のファイルパスは試合JSONへ含めません。

不正利用防止のため、Firebase上の利用者IDごとに共有・更新回数と最終実行時刻を保存します。この利用量情報は公開せず、投稿制限の判定にのみ使用します。

共有された試合データは一覧検索できませんが、対応するYouTube動画IDを知る利用者は取得できます。プレイヤー名などを共有したくない場合は、投稿前に匿名化オプションを選択できます。

5. 保存期間と削除

認証トークンは、利用者が本アプリ内でGoogle接続を解除するまで、またはGoogle側で認可を取り消すまで、利用者のPCに保存される場合があります。利用者が「Google接続を解除」を実行すると、本アプリはローカルの認証情報を削除し、Googleの認可取消エンドポイントへ取消要求を送信します。

本アプリは、利用者がYouTubeへ投稿した動画そのものを開発者のサーバーへ複製・保存しません。

Firestoreへ共有した試合データは、削除されるまで保存されます。削除を希望する場合は、対象のYouTube動画URLを添えて下記の問い合わせ先へ連絡してください。認証トークンやパスワードを送る必要はありません。

6. 第三者サービス

本機能はGoogleおよびYouTubeのサービスを利用します。Googleによる情報の取扱いについては、Googleプライバシーポリシーを確認してください。

7. 問い合わせ

本ポリシーまたは本機能に関する問い合わせは、GitHub Issuesから受け付けます。個人情報、パスワード、access token、refresh tokenは送信しないでください。

安全性に関する説明

共有された試合JSONを読み込む際の検査、不正データへの対応、現在の制約については、安全性と共有データを確認してください。

8. 改定

本ポリシーを改定する場合は、このページの最終更新日を変更して公開します。

Google認証情報は試合データとして共有されません。問い合わせ時にもパスワードや認証トークンを送信しないでください。
