LeagueRecord Custom English

オープンソース Windows デスクトップアプリ

ローカルに録画し、選んだときだけ投稿。

LeagueRecord Customは、League of LegendsのゲームプレイをWindows PCへ録画します。任意のYouTube機能では、利用者が選択した完成済み録画またはクリップを、認可した自身のYouTubeチャンネルへ投稿できます。

GitHubでソースを見る Googleデータの利用方法
基本はローカル

録画と動画管理はPC上で行います。利用者が動画を選び、明示的に投稿を開始しない限りアップロードしません。

自分のチャンネルと設定

システムブラウザでGoogleアカウントを接続し、タイトル、説明、公開範囲、子ども向け設定、サムネイルを確認してから投稿します。

YouTube APIの利用

LeagueRecord Customは、利用者が許可した動画投稿、カスタムサムネイル、投稿処理状況の確認、および本アプリで共有した動画の存在確認にYouTube API Servicesを使用します。一般的なYouTube利用状況の収集・分析には使用しません。
